# HRAnalytics
This project focuses on analyzing employee data to identify the main reasons behind employee attrition and improve HR decision-making.

Using Python libraries like Pandas, NumPy, Matplotlib, and Seaborn, I cleaned and analyzed the dataset to find patterns related to employee performance, salary, job satisfaction, overtime, department, and work environment.

Project Objectives:
Analyze employee attrition trends
Identify factors affecting employee turnover
Compare departments based on employee performance
Visualize HR data using charts and graphs
Generate business insights for better workforce management
Key Steps Performed:
Data Cleaning & Preprocessing
Handled missing values
Removed duplicates
Formatted data properly
Exploratory Data Analysis (EDA)
Attrition analysis
Salary distribution
Job satisfaction comparison
Department-wise analysis
Data Visualization
Bar charts
Heatmaps
Pie charts
Count plots
Insights Generated
Employees working overtime had higher attrition
Low salary and low job satisfaction increased employee turnover
Some departments showed higher attrition rates compared to others
Technologies Used:
Python
Pandas
NumPy
Matplotlib
Seaborn
Jupyter Notebook

This project helped me strengthen my skills in data analysis, visualization, and business insight generation using Python.
